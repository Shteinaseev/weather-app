# Weather App

Современное веб-приложение для отображения погодной информации с интерактивной картой и расширенными прогнозами.

## Описание

Weather App — это полнофункциональное приложение для просмотра текущей погоды и прогнозов на базе современных веб-технологий. Приложение использует MapTiler для отображения интерактивных карт и Weather API для получения актуальной информации о погоде.

## Особенности

- Интерактивная карта с визуализацией погодных данных
- Графические индикаторы параметров погоды (температура, влажность, ветер)
- Прогноз погоды на несколько дней
- Отдельные наборы иконок для дневного и ночного времени
- Анимированные компоненты и стильный интерфейс
- Быстрая загрузка и оптимизированная производительность

## Технологии

- **Vite** — быстрый сборщик проектов и dev-сервер
- **MapTiler SDK** — интерактивные карты
- **MapTiler Weather API** — данные о погоде в реальном времени
- **CSS3** — современные стили и анимации
- **Vanilla JavaScript** — чистый JavaScript без фреймворков
